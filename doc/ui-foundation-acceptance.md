# UI Foundation 审查收尾验收

日期：2026-10-03。范围：本次审查提出的控件复用、键盘缺口、错误反馈、视觉强调和验收记录；不增加功能或改变任务领域行为。

## 本轮实现

- 共享 DropdownMenu / DropdownMenuItem 使用已安装的 Reka UI；分类、清单和 AI 模型菜单获得键盘导航、选中语义、Escape 关闭及焦点恢复。
- 悬浮任务卡接入共享 ContextMenu，支持 Shift+F10 与 Context Menu 键。菜单打开状态继续参与面板自动隐藏抑制。
- 列表完成与多选、悬浮步骤、报告全选和逐项选择复用 Checkbox；新增半选属性、可见减号与 mixed 语义。普通动作复用 Button / IconButton，最小点击区为 28×28。
- 悬浮面板的分类、固定、元信息、菜单与空态图标改为明确导入的本地 Lucide；不改品牌及系统托盘资产。
- 报告模型菜单和新建/列表模型选择器复用共享菜单；原生报告类型 select 保留并提供可访问名称。
- 时间筛选采用基础按钮，AI 报告取消独立渐变，未选中的过期筛选采用中性样式；选中过期筛选保持危险色。清单名称恢复正文色，图标保留清单自定义颜色。
- 主内容取消外卡片边距、圆角与阴影，以背景和侧边分隔线组织；宽高计算同步更新，不改平台窗口材质或标题栏职责。
- Inspector 时间校验显示现有字段错误；开始任务失败使用当前窗口普通 Dialog，保留服务错误与原任务。没有新增业务 IPC 或通知系统。
- 删除迁移产生的 Checkbox、AI 菜单及悬浮控件重复样式。阶段日志保留为历史记录，Spec 状态指向当前验收。

## 验证

- renderer 构建通过。构建仍有原有大 chunk / browserslist 提示，本轮不升级工具链。
- 完整 Electron E2E：95/95 通过；包括既有 Today、列表/看板危险操作、设置、菜单栏、悬浮、跨窗口同步及离线冷启动。
- 最终半选视觉与模型入口收口后，重新构建并重跑 5 个受影响场景，全部通过。
- 新增键盘回归：分类/清单菜单、步骤完成、右键菜单 Escape 恢复；报告全选半选、模型菜单 Escape 不关闭父 Dialog；开始任务失败保留任务。
- 五套主题（默认、Twitter、Vercel、Morandi、Mint Green）×浅色/深色：实际列表正文、报告任务正文对比度均至少 4.5:1。计算考虑半透明背景叠加，不仅检查 token 非空。
- 保存五套主题明暗列表/报告截图；检查代表性深色报告、默认浅色列表与窄窗口表单。窄窗口使用真实 Electron setSize，并接受应用现有最小窗口宽度。
- 单元测试：122/123 通过。`test/ai-task-time.test.js:47` 使用 2026-09-25 的固定绝对提醒；当前时间已超过它，`AIService.normalizeGeneratedTasks` 按既有规则清除过期提醒，导致预期 absolute 与实际 null 不符。测试及 AI 服务文件均未被本轮修改；未为 UI 收尾改变日期业务规则。

截图与完整测试日志保存于 `.scratch/ui-foundation-20261003/`（本地验收产物，不加入业务打包）。截图可供维护者复查，不构成全应用像素级验收。

## 验收边界

- 当前环境为 macOS。Windows 材质、标题栏安全区域、缩放、鼠标穿透与悬浮行为未验证。
- 本轮五套主题视觉证据覆盖列表与报告表单；没有宣称对所有日期选择器、图表、设置及危险弹层完成明暗组合的全面对比度检查。
- 本轮为审查所列问题的收尾，不把其他活跃区域仍存在的历史自建控件宣称为已全部迁移。后续修改这些控件时继续遵循 components/ui 复用规范。
- 全量迁移目标仍以两份 Spec 为准；已知失败和未验证平台应保留，不能写成“所有检查全绿”或“全平台完成”。
