# 重复任务与悬浮面板修复验收

日期：2026-10-13。验证平台：macOS，独立 Electron 用户目录和临时 SQLite；未操作真实用户任务。Windows/Linux 未验证。

## 行为

- 重复任务的安排开始、结束、截止只选择时刻，编辑器注明应用到后续重复任务；普通任务仍选日期。
- 从虚拟实例编辑时刻时定位活动系列，首项完成后也不会改写历史头行。
- 修改时刻更新未来虚拟实例和今天/未来的未完成物化实例；保留完成历史与实例备注。早于开始的结束时刻表示次日结束。
- 当天创建的周/月/年重复按本地日期生成当天实例；无日期头行合并后保留发生日期，进入今天而非收件箱。
- 主进程广播包含悬浮面板；监听在初次加载前注册，并在卸载时只移除自身监听。
